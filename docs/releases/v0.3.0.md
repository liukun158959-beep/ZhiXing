# tebb v0.3.0 · 一起研究，一起动手

知行 · ZhiXing 正式更名为 **tebb**。这一版以伙伴聊天为核心，把协作、项目编码、资料和笔记放进同一个工作区；桌宠作为可选的轻量入口。

## 更新亮点

- **和伙伴一起工作**：与小缇、阿探、墨墨、码可私聊或组建协作群，自定义头像、性格、模型与工具。提供独立的新建群聊图标；@ 和 Skill 菜单按窗口空间展开。统一发送，支持指定参与者、附件和 Markdown；对话记录与伙伴目录分开。协作按有限分工执行，后台任务可补充要求与停止。
- **打开文件夹，直接进入项目**：选择项目即可浏览文件与预览内容，分别授权文件编辑和本地命令。编码伙伴可以读取约定、修改文件、运行构建/测试，并展示真实差异和退出码。代码示例不再要求先配置目录；切换项目不沿用旧项目的写入授权。
- **让笔记继续参与协作**：已完成回答可收藏为笔记，按任务去重并标注 AI 生成来源；笔记可作为完整只读附件带回伙伴聊天，不自动发送。保留知识库来源问答、视频学习与飞书归档；视频页提供登录入口与登录态管理。
- **轻巧桌宠与一致的工作区**：内置48px圆形小伴，支持调节大小与换色。单击切换浮动聊天，支持置顶、新对话、@ 与 Skill；收起后保留任务进展。全局左侧导航、顶部工具栏及工作台布局统一，侧栏实际占据空间，窄窗口上下排列。
- **读取仓库，看清执行过程**：具有扩展只读工具权限的伙伴，可使用 GitHub CLI 登录态发现自己的仓库，读取目录、README 与源码，包括自己的私有仓库，无需克隆。工作目录入口移至聊天顶部。设置中可选择模型调用的系统代理、直连或自定义代理；开发者模式展示调用链和 HTTP 各阶段耗时。改进进程预热、路由、工具参数流与编码命令等待，并区分模型、工具和总时限；已执行操作不会自动重放。

## 下载与升级

下载 `tebb-0.3.0-windows-x64.zip`，完整解压后运行 **tebb.exe**，保留旁边的 `runtime` 文件夹。

- 支持 Windows 10/11 x64，需要 WebView2 Runtime；当前程序尚未代码签名。
- 从旧版升级时，先退出旧程序，再替换程序目录；用户数据继续使用 `%LOCALAPPDATA%/DeskCompanion`，更名不重置原有配置、聊天和登录态。
- 自行配置模型 API 地址、模型 ID 与 API Key。工具执行要求模型支持 tool calling；模型调用可能计费。
- 文件/命令权限按工作目录配置。编码验证依赖本机 WSL、Ubuntu、Python3 与 bubblewrap，未提供可用沙箱时拒绝回退到宿主执行。
- 飞书、GitHub、知识库模型与视频平台登录按需准备，参见随包使用说明。可选 Live2D 素材与个人模型权重不随包提供。

## 运行边界与已知问题

当前是本机工作区。关机后定时任务不会在云端继续；尚未提供云端常驻、多人在线服务或云沙箱。

模型上游偶发等待响应头超时仍在跟踪，真实模型 P99 尚未达标；部分搜索请求会转到备用来源。视频总结基于实际取得的字幕，不宣称已经读取视频画面。停止或超时保留已有操作回执，重新执行前需核实已有写入。
