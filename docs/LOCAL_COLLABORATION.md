# tebb 统一工作区

本功能在 main 分支运行，尚未发布新安装包。当前是本机单工作区；后端关闭后任务不会云端续跑。

## 使用

1. 打开桌面客户端，默认进入伙伴聊天。左侧全局导航、二级栏与顶部工具栏保持固定结构；页面在固定内容区域内替换，只有轻微透明度过渡，不对布局和嵌套 section 添加缩放/位移动画。聊天采用全局字体、主题色及控件边框。
2. 单聊和群聊统一发送。普通交流直接回答，执行请求由模型识别后进入后台任务。`@` 一位伙伴交给该伙伴；多人 `@` 由协调者在所选范围组织有限分工。成员选择支持筛选、方向键、Enter、Esc 和中文输入法。
3. `+ 附件` 选择只读资料快照；`/ Skill` 选择仓库现有技能。标签保留在当前会话草稿，发送后清空，不带入其他会话。工具授权可从输入区的「工具」或伙伴配置中调整。技能提供流程指引，不扩大工具权限；当前扩展工具只提供飞书日程/任务、GitHub 近况及日志等只读能力。
4. 顶部「打开文件夹」直接调用本机文件夹选择器，选择后立即保存主目录并展示项目文件树，无需手填路径。聊天输入区也显示当前工作目录，可点击打开侧栏；未设置时有明确入口。新目录默认只读；在「目录与权限」分别允许编辑和本地命令并保存后，重新发送需要保存/验证的任务。切换新目录不会继承旧目录的授权和参考目录；取消选择保持现状。最多四个只读参考目录，目录不能重叠。开发者模式不授予执行权限。
5. 文件按目录层级读取，支持筛选、代码高亮、Markdown 阅读/源码、常见图片以及已支持文档的正文提取。可引用选中文本或文件片段到聊天，引用不会自动发送。
6. 编辑已授权主目录中的 UTF-8 文本，保存时校验文件哈希和工作区授权版本。遇到外部修改会保留草稿并拒绝覆盖；「读取最新版本」保留编辑内容供差异合并。切换文件、收起侧栏、切页保留草稿和阅读位置；存在未保存文件时不能关闭项目标签或切换工作目录。
7. 添加编码伙伴「码可」，配置模型后可单聊，或在协作群的「邀请或调整伙伴」中加入。要求代码示例或算法讲解时，即使未打开文件夹也会调用模型直接给出代码，不冒充已保存或运行；只有实际读写项目与运行命令才使用授权目录。它能读取约定、编辑代码、实际运行构建/测试，在预算内修复失败。任务卡和执行任务页展示文本差异、命令输出及退出码；后续改动会让先前验证标为过期。
8. 允许本地命令后，顶部终端绑定主目录与本次授权版本，和编码任务共享目录锁。未授权项目命令时，原有会话隔离终端仍可使用；界面明确显示执行位置。编码任务的命令也能在终端记录中读取和停止。

## 普通模式与开发者模式

- 模型、工具、Skill、附件、任务进度、文件改动、验证结果及用量属于普通功能。模型选择按会话保留，伙伴昵称、性格和头像可编辑。
- 连续五击左侧 tebb. 下方的版本号开启或关闭开发者模式。偏好保存在本机，品牌区显示 DEV MODE。
- 参数调试、手动会话摘要、私有偏好编辑、完整执行事件与调用记录归入开发者模式。摘要只作用于当前会话，原消息保留；它不是自动提炼的长期记忆。模型上下文仍有容量限制，需检查摘要覆盖范围。
- 普通聊天的内部路由不显示成后台任务卡。普通回答直接接收 Markdown，包括代码块，无需先转义成 JSON。真正需要执行时，模型通过 start_background_task 函数请求后台工作；这里只登记，工具在后续授权任务中执行。保留旧 JSON 协议兼容，格式错误在原两轮预算内纠正一次；不重放工具。内部路由使用 low 推理，实际执行保留用户采样配置。需要执行时显示真实任务；协调者只生成一层、最多两项工作，执行者不能继续委派。

## 数据、权限和执行

- 历史聊天从原 JSONL 一次性复制到协作工作区，以相同界面续聊；原文件不修改。迁移前保存 `memory/collaboration/workspace.before-unified.sqlite3`。删除历史会话只删除统一工作区副本，源文件及诊断备份保留，确认弹窗说明这一点。
- 伙伴使用自己的角色、模型、工具、私有偏好；共享的是当前会话公开内容与用户选定资料。任务持有提交时的配置快照；工作目录授权变更会使旧授权请求失效。
- 主目录写入有进程间租约。同一工作目录的编码任务串行，用户编辑在写任务期间明确拒绝。任务取消同时停止关联命令；租约/心跳失效也会结束沙箱进程。
- 命令复用 WSL + bubblewrap：主目录绑定到 `/workspace`，参考目录只读绑定到 `/references/N`，不开放网络，不传宿主凭据环境，不挂载宿主磁盘根。代码直接修改授权主目录，本版未提供 Git 工作树/分支合入管理。
- 文件 API 拒绝越界、符号链接/目录联接、硬链接、`.git`、`.env*` 等路径；**命令权限允许操作整个授权主目录**，不是按文件 API 黑名单过滤命令。
- 编码验证开启 `set -e` 与 `pipefail`，防止普通尾随命令或管道覆盖失败退出码。命令成功只代表该命令完成，不能证明任意业务需求都满足。报告保留实际验证范围，无法运行的检查不能标成通过。
- 默认最多两项长任务和一条聊天并行。普通工作累计最多六轮模型调用、两次搜索、四次网页读取；内置编码伙伴最多十二轮，任务最长十分钟，单个验证命令最多两分钟。环境中的编译器与依赖须已经可用；无网络沙箱无法自动下载依赖。
- 文本/图片预览上限 1 MiB，项目文件最多同时打开十二个标签。命令差异采集覆盖最多2000个、合计16 MiB的UTF-8文本，跳过依赖/构建目录和二进制；达到上限时回执会注明。超过限制的文件可从附件提取或原生应用读取。

## 浏览器体验与验证

交互演示：`/client.html?preview=chat`。真实聊天体验：`/client.html?preview=chat&live=1`，通过 `scripts/preview_collaboration.py` 生成两小时临时凭证。凭证仅允许联网只读协作，不能配置工作目录、访问文件 RPC、添加编码伙伴或启用本地工具；完整本地能力在桌面客户端使用。

验证包括前端组件交互、真实 RPC、历史迁移、目录授权和写入冲突、工具隔离、任务依赖和取消，以及独立 WSL 项目的失败→修改→测试通过、参考目录写入拒绝。真实模型也完成了读取、修改、执行测试及汇报闭环。当前模型提供商经系统代理仍可能连接失败；本次完整模型验证使用独立脚本直连，未改系统代理配置。

搜索与引用的证据边界、诊断方法见 [搜索诊断](SEARCH_DIAGNOSTICS.md)。

## 页面与桌宠

已访问页面保留实例、输入与阅读位置，隐藏时暂停列表轮询；首次读取使用固定结构占位。聊天标题右侧以图标打开任务、伙伴、待办，悬停可查看名称；模型选择只展示模型名，默认条目沿用实际接收伙伴的配置，不改变伙伴身份。

设置页的「桌宠形象」提供纸白、鼠尾草、墨黑三种配色；内置形象是纯圆加两只眼睛，默认48px，可调整为32～64px。SVG矢量绘制无需Core，保留拖动、点击反馈与右键菜单，也可使用已有凯尔希Live2D素材。皮肤与大小保存在本机，独立于Agent人格。

单击圆点切换340×420px的原生浮动聊天框，再次单击会收起。默认不置顶，点击其他界面自动收起；顶部图钉可开启/取消置顶，置顶后保持显示。收起窗口保留当前置顶状态、草稿和任务，不会取消任务。支持输入、@伙伴、/Skill、模型选择和完成后的Markdown展示，与主窗口共用会话及任务。运行中追加真实文字、状态与工具回执，仅新增文字淡入，执行标记有轻微光效；减少动态效果时禁用动画。任务记录持续保留，不按4秒清空，不展示内部推理。右键或×可隐藏对话框，任务继续；重新打开恢复记录、输入和阅读位置。「在主窗口打开」会先选择同一会话。

默认人设改为tebb工作伙伴：自然、简洁、依据工具回执报告结果，区分事实和推断，并明确验证范围。旧版原始默认人设在备份到`user_state.before-tebb-persona.json`后迁移；自定义人设保留。伙伴仍有独立角色和性格，桌宠换肤不会切换人格。

浮动输入框的 @ 只列出当前会话成员，/ 列出已安装 Skill，可按名称或描述过滤；方向键、Enter/Tab 选择、Esc 收起，中文输入法确认不提交。Skill 以标签保留在当前会话，发送时明确带入请求，不能扩大工具权限。

文件/网页/终端侧栏统一由顶部工具栏「打开侧栏／收起侧栏」恢复和收起，聊天区不再叠放恢复按钮，避免遮挡协作详情的关闭图标。任务、伙伴、待办图标使用透明背景。

收起浮动聊天后，圆点旁持续展示最近一轮真实进度与流式答复摘要，完成、超时或失败时保留结果提示；不按短台词的4秒时限清空。右键「关闭提示」会静音这一轮及其子任务，新消息仍可提示。打开聊天框时收起重复气泡，启动客户端不会重放旧的已完成/失败任务。关闭任务进度设置会同时关闭这类提示和忙碌光效。

协作工作进程使用轻量 OpenAI 兼容流式传输，避免每条消息冷加载整个 Atlas 框架；工具权限、任务队列、独立进程停止与超时仍由原调度器控制。纯问候（例如 `hello`）在自动模式直接流式回答，仍携带本会话上下文；包含 @、Skill、附件或执行要求时保留原模型路由。研究引用指令只加入执行任务。模型请求按设置中的网络方式连接并保留TLS验证，不在失败后自动改用其他模型或重放工具调用。模型服务的首段输出仍可能较慢，不能保证即时回复。

浮窗右上角统一为SVG图标；「创建新对话」为当前伙伴打开新会话，保留原草稿与后台任务。模型代理设置、一次性进程预热、P99测试和已知上游长尾见 [性能验证](PERFORMANCE.md)。调试窗口新增「耗时分析」，可直接关联伙伴聊天的执行队列。


## 2026-10-16 交互与工具回归

- 对话和伙伴分为两个标签：对话显示会话，伙伴目录负责查看配置和创建新对话，不再把同一对象在一列里重复排列。删除历史不删除伙伴。
- 文件/网页/终端工作区实际占据网格列，聊天输入和发送按钮随剩余宽度调整；窄窗口改为上下分区。任务/伙伴详情在窄区域停靠到底部，并为聊天留出空间。桌宠右键移除重复的开关聊天项，保留单击圆点切换。
- 已完成回答可「收藏到笔记」，按实际 run 去重，明确标记 AI 生成、未额外核验；任务登记消息及失败/未完成回答不能收藏。知识库中的笔记支持「作为资料交给伙伴」，将完整正文与引用制成只读附件快照，加入当前会话草稿，不自动发送。
- 监控台的调用/总时限现在也应用于之后提交的伙伴任务，不再写死90秒；已有任务不修改。WSL编码命令采用自身上限（最多120秒）加20秒收尾等待，总任务时限仍有效。持续接收函数参数也计为模型进展；GLM工具调用按官方协议回传同一任务内的模型推理块，不将其作为聊天文字发布。
- 自动测试、真实模型/WSL和联网验证结果见 [工具回归记录](TOOL_REGRESSION_20261016.md)。上游未返回响应头的偶发超时仍需核实接口服务，不能保证通过客户端修改消除。


## 发布前交互与仓库阅读补充

新建协作群的独立多人图标固定在会话栏标题旁，在对话/伙伴两个标签都可见。工作目录移至聊天标题栏，以文件夹图标与目录短名呈现，悬停显示完整路径。

主窗口与浮窗的 @ / Skill 选择共用视口浮层：根据输入区上/下空间定位，长列表在菜单内部滚动，不被输入区或消息区裁切。

已授权「扩展只读工具」的伙伴可使用 `github_repository` 发现本人仓库、读取README/目录/文本源码，沿用本机 `gh` 登录，可读本人私有仓库。没有本地目录和命令权限也可分析仓库；不能据此修改远程或本地文件。第三方公开仓库使用明确 owner/name。凭据文件、链接/子模块与过大或二进制文件拒绝读取；工具结果保留文件SHA、分页和真实来源链接。

GitHub CLI 的网络和登录与模型网络策略分开。模型设置中的直连不会改变 gh 的代理；私有仓库应通过已登录工具读取，不能通过匿名网页代替认证。来自实际工具结果的链接会登记为可发现来源，网页读取仍进行原有公网与SSRF检查。

模型一次请求超过剩余搜索/网页预算时，执行预算内请求，对其余调用返回未发送的限额回执，不再整批终止，也不提高总预算。
